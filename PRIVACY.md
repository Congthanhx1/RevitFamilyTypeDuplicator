# Privacy Policy

Last updated: August 20, 2026

CopyFam operates entirely inside Autodesk Revit on the user's computer.

## Data collection

CopyFam does not collect, store, transmit, sell, or share personal information, Revit model data, Family data, usage analytics, credentials, or device identifiers.

## Network access

The add-in does not make network requests. The contextual Help command opens the public project documentation in the user's default web browser only when the user requests help.

## Local changes

When the user confirms the command, CopyFam modifies only the active Revit document by creating new Family Types. These changes remain under Revit's normal transaction and undo controls.

## Third parties, retention, and deletion

Because CopyFam collects no data, no user data is provided to third parties, retained, or processed for deletion. Revit project changes can be undone or removed by the user within Autodesk Revit.
